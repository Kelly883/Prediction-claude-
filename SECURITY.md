# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability, please report it responsibly.

**Do not** open a public GitHub issue for security vulnerabilities.

Instead, please report via one of these channels:

- **Email:** security@predictpro.com
- **GitHub Security Advisory:** Use the "Security" tab on GitHub to privately report

Include as much detail as possible:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You should receive a response within 72 hours.

## Security Updates

Security patches are released as soon as possible after a vulnerability is confirmed. We recommend always using the latest patch version.

## Public Disclosure

We follow coordinated disclosure. Please do not publicly disclose details until we have had a chance to investigate and release a fix.
